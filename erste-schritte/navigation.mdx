TrendVoice ist über eine seitliche Navigationsleiste (Sidebar) strukturiert. Bewegt die Maus an den linken Bildschirmrand, um die Sidebar ein- oder auszublenden.

![Sidebar-Navigation mit dem Bereich CHAT](/images/trendvoice/TrendVoice-Side-Menu.png)

## Menübereiche im Überblick

| Bereich | Inhalt |
| --- | --- |
| HAUPTMENÜ | Dashboard mit Übersicht |
| VOICE | Voice Agent, Anrufliste, Callcenter, Telefonbuch, SMS |
| CHAT | Chat Agent (Konfiguration) und Chats (Konversationsübersicht) |
| LEADS | Lead-Management |
| KONNEKTOREN | Integrationen mit externen Systemen |
| EINSTELLUNGEN | Unternehmens- und Profileinstellungen |
| ZAHLUNGEN | Abrechnung |

## Mandanten und Projekte

Oben in der Sidebar seht ihr den Namen eures Unternehmens oder Projekts (z. B. _Defib Warehouse_). Alle Einstellungen beziehen sich auf diesen Mandanten. Wenn ihr mehrere Mandanten verwaltet, wählt ihr den gewünschten Mandanten über die Projektauswahl in der Sidebar.
