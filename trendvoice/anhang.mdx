## Glossar

- **Chat Agent** — KI-gestützter Chat-Assistent, der Besucher auf eurer Website begrüßt und Fragen beantwortet.
- **Knowledge Base** — Wissensdatenbank; Sammlung von Quellen (Webseiten, Dateien), aus denen der Agent Antworten ableitet.
- **Widget** — das eingebettete Chat-Fenster auf eurer Website.
- **Playground** — Testbereich in TrendVoice, um den Chat Agent vor dem Live-Einsatz zu prüfen.
- **Snippet-Code** — HTML/JavaScript-Code zum Einbinden des Chat-Widgets auf eurer Website.
- **Voice Agent** — KI-gestützter telefonischer Assistent, der eingehende Anrufe annimmt.
- **Lead** — Kontaktanfrage oder Interessent, der über ein Formular oder den Chat erfasst wurde.
- **Mandant** — euer Unternehmen oder Projekt in TrendVoice; alle Einstellungen gelten mandantenspezifisch.

## Go-Live-Checkliste Chat Agent

Bevor ihr den Chat Agent auf eurer Website freischaltet, prüft:

- Begrüßungstext gespeichert
- Mindestens eine Knowledge Base mit Status **Fertig**
- Formular konfiguriert (falls gewünscht)
- Playground-Tests bestanden (Begrüßung, Wissensfrage, Formular)
- Snippet-Code auf Website eingebunden

## Häufig gestellte Fragen (FAQ)

**Wie öffne ich die Sidebar?**
Bewegt die Maus an den linken Bildschirmrand.

**Warum sehe ich meine Änderungen nicht?**
Habt ihr auf **Speichern** geklickt? Ladet danach den Playground neu (**Widget laden**).

**Der Chat Agent antwortet „weiß ich nicht" — was tun?**
Prüft, ob mindestens eine Knowledge Base den Status **Fertig** hat und relevante Inhalte enthält.

**Ich kann den Snippet-Code nicht selbst einbinden — was tun?**
Leitet den Code an eure IT-Abteilung oder Webagentur weiter. Der Code wird vor dem schließenden `</body>`-Tag eingefügt.

**Wo finde ich erfasste Kontaktdaten?**
Unter **LEADS** → **Lead-Management** (siehe [Leads](/trendvoice/leads)).

**Wo sehe ich vergangene Chat-Verläufe?**
Unter **CHAT** → **Chats** (siehe [Chats](/trendvoice/chat/chats)).

## Datenschutz und Support

**Datenschutz:** TrendVoice verarbeitet Chat- und Anrufdaten im Auftrag eures Unternehmens. Stellt sicher, dass eure Datenschutzerklärung die Nutzung von KI-Chat und Voice-Agenten auf eurer Website erwähnt. Bei Fragen zum Speicherort oder zur Löschung von Daten wendet euch an den TrendVoice-Support.

**Support:** Wenn ihr ein Problem nicht mit dieser Dokumentation lösen könnt, kontaktiert euren TrendVoice-Ansprechpartner oder den Support.
