Der Playground ist ein sicherer Testbereich, um den Chat Agent zu testen, bevor er auf eurer echten Website eingebunden wird. Eure Website-Besucher sehen nichts davon.

## Navigation

Sidebar → **CHAT** → **Chat Agent** → Bereich **Playground**

## Schritte

<Steps>
  <Step title="Konfiguration abschließen">
    Die Konfiguration in [Agenten-Konfiguration](/trendvoice/chat/agenten-konfiguration), [Knowledge Bases](/trendvoice/chat/knowledge-bases) und [Formular-Konfiguration](/trendvoice/chat/formular-konfiguration) abschließen und alle Änderungen speichern.
  </Step>
  <Step title="Playground öffnen">
    Bereich **Playground** aufklappen.
  </Step>
  <Step title="Widget laden">
    Auf **Widget laden** klicken.
  </Step>
  <Step title="Prüfen">
    - Wird der Begrüßungstext korrekt angezeigt?
    - Antwortet der Agent sinnvoll auf Wissensfragen?
    - Wird das Formular bei Bedarf angezeigt? (falls konfiguriert)
  </Step>
</Steps>

## Ergebnis prüfen

Alle drei Tests bestanden? Dann ist der Agent bereit für die [Widget-Integration](/trendvoice/chat/widget-integration).

## Häufige Probleme

| Problem | Lösung |
| --- | --- |
| Alte Version wird angezeigt | Seite neu laden, erneut **Widget laden** |
