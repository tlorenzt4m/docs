Eine **Knowledge Base** (Wissensdatenbank) ist eine Sammlung von Quellen wie Webseiten, PDFs oder Produktdaten, aus denen der Chat Agent Antworten ableitet.

## Wofür brauchen wir das?

Damit der Chat Agent inhaltlich korrekt auf Fragen zu euren Produkten, Services und Website-Inhalten antworten kann.

## Navigation

Sidebar → **CHAT** → **Chat Agent** → Bereich **Knowledge Bases**

## Schritte

<Steps>
  <Step title="Bereich öffnen">
    Bereich **Knowledge Bases** aufklappen.
  </Step>
  <Step title="Neue Knowledge Base anlegen">
    Auf **\+ Neu erstellen** klicken. Der Dialog _Neue Knowledge Base erstellen_ öffnet sich.

    ![Dialog Neue Knowledge Base erstellen](/images/trendvoice/KB-Neu-erstellen.png)
  </Step>
  <Step title="Name vergeben">
    Im Pflichtfeld **Name** einen aussagekräftigen Namen eintragen (max. 40 Zeichen, z. B. _„Defib Warehouse GB Website"_).
  </Step>
  <Step title="Quellentyp wählen">
    Quellentyp über die Registerkarten wählen:

    - **URL scrapen** — Webseiten per URL oder Sitemap einlesen
    - **Text** — Text direkt eingeben
    - **Datei** — Dateien hochladen (z. B. PDF)

    Bei **URL scrapen**: URL eingeben (z. B. `https://example.com`) und auf **\+** klicken, oder **Sitemap** nutzen, um URLs automatisch zu erkennen.
  </Step>
  <Step title="Erstellen">
    Auf **Erstellen** klicken. Bei Bedarf mit **Abbrechen** abbrechen.
  </Step>
  <Step title="Status abwarten">
    Warten, bis der Status **Fertig** (grün) neben dem Eintrag erscheint.
  </Step>
  <Step title="Verwalten">
    Bei Bedarf auf **Verwalten** klicken, um bestehende Quellen zu bearbeiten oder zu entfernen. Refresh-Symbol nutzen, um die Liste oder einzelne Quellen zu aktualisieren.
  </Step>
</Steps>

## Tipps

- Quellen sinnvoll trennen (Website, Produktdaten, FAQ-PDF).
- Aussagekräftige Namen vergeben (z. B. _„\[Ihr Unternehmensname\] Website"_).
- **Sitemap** nutzen, um viele Unterseiten einer Website auf einmal zu erfassen.

## Ergebnis prüfen

Im [Playground](/trendvoice/chat/playground) eine inhaltliche Frage stellen (z. B. zu AED-Produkten). Der Agent sollte mit Wissen aus der Knowledge Base antworten.

## Häufige Probleme

| Problem | Lösung |
| --- | --- |
| Status bleibt nicht **Fertig** | Quelle prüfen, Refresh-Symbol nutzen |
| Agent antwortet „weiß ich nicht" | Richtige Knowledge Base aktiv? Status **Fertig**? |
